PostgreSQL 已成功部署到 namespace {{ .Values.namespace }}。

Release:
  {{ .Release.Name }}
Service:
  postgres:{{ .Values.postgres.service.port }}

检查部署状态：
  kubectl --kubeconfig=<你的 kubeconfig 路径> get pods,svc,statefulset,pvc -n {{ .Values.namespace }}

查看数据库日志：
  kubectl --kubeconfig=<你的 kubeconfig 路径> logs -n {{ .Values.namespace }} statefulset/postgres --tail=100

验证 PostgreSQL 是否就绪：
  kubectl --kubeconfig=<你的 kubeconfig 路径> exec -n {{ .Values.namespace }} postgres-0 -- pg_isready -U <数据库用户名> -d {{ .Values.postgres.database }}

验证 pgvector 扩展：
  kubectl --kubeconfig=<你的 kubeconfig 路径> exec -n {{ .Values.namespace }} postgres-0 -- psql -U <数据库用户名> -d {{ .Values.postgres.database }} -c "SELECT extversion FROM pg_extension WHERE extname='vector';"
