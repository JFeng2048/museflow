# 服务架构设计

**一句话概括**：后端是 Go 微服务单体仓库（gRPC + Gin），对外只有 api-gateway 一个 HTTP 边界，业务逻辑集中在 user-service，前端是 Vue 3 + TS + Vite 的 SPA。

## 总体架构

```
                ┌─────────────┐
   Browser ───▶ │ api-gateway │ :5001  (Gin HTTP, Swagger, JWT 校验, Cookie 管理)
                └──────┬──────┘
                       │ gRPC
                ┌──────┴──────┐
                │ user-service│ :5002  (认证/用户/RBAC/2FA/审计)
                └──────┬──────┘
        ┌──────────────┼──────────────┐
     PostgreSQL    Redis          (外部 SMTP)
    user_svc    令牌白/黑名单     邮件验证码
```

浏览器只与 api-gateway 通信，前端通过 `/api/v1/**` 访问；服务之间用 gRPC，对外不暴露。
部署形态、入口分层与网络可达性见[部署架构](部署架构.md)。

## 模块划分

| 路径 | 类型 | 职责 |
|------|------|------|
| `pkg/envloader` | 共享库 | 分层 `.env` 加载，服务前缀键 + 共享无前缀键 |
| `pkg/errcode` | 共享库 | 统一错误码（2xxx 成功 / 4xxx 客户端 / 5xxx 服务端），中英双语 |
| `pkg/logger` | 共享库 | `slog` + `lumberjack` 结构化日志 |
| `proto/user` | 契约 | gRPC proto 与生成代码 |
| `services/user-service` | 服务 | 用户域全部业务逻辑（含异步 worker） |
| `services/api-gateway` | 服务 | HTTP 边界、路由、中间件、gRPC 客户端 |
| `services/crawl4ai-service` | 服务 | 爬虫 / 内容抽取（HTTP + gRPC 双接口） |
| `web` | 前端 | Vue 3 + TS + Vite SPA，构建产物由 Nginx 托管 |

## 分层与依赖约束

- **单向依赖**：`handler → service → repository`，禁止反向。
- user-service 内部进一步拆分：`auth` → `token` + `dto`；`token`/`dto` 不反向依赖 `auth`。
- 配置统一走 `envloader`，禁止直接使用 `os.Getenv`。
- 业务错误在 `auth` 包定义为 `errors.New`，由 handler 映射为 gRPC status，绝不裸传。

## 数据持久化

- PostgreSQL schema 固定为 `user_svc`，表 `user_svc.users` 由 `services/user-service/database/user_svc.sql` 定义。
- Redis 负责：refresh token 白名单、access token 黑名单、设备会话列表、权限缓存。
- 密码使用 bcrypt 加密；SSO 用户密码字段可空。

## 关键设计

- **双令牌**：access（无状态 JWT，1h）+ refresh（JWT + Redis 白名单，30d，HttpOnly Cookie），见[双令牌认证系统设计文档](../develop/双令牌认证系统设计文档.md)。
- **2FA**：TOTP 两步登录 + 恢复码，见[2FA 双因素认证设计文档](../develop/2FA双因素认证设计文档.md)。
- **权限**：内置三角色 + 权限码比对，见[权限验证设计文档](../develop/权限验证设计文档.md)。
- **人机认证**：登录/注册接入 Cloudflare Turnstile，校验允许的 hostname 来自部署域名，见[人机认证实现文档](../develop/人机认证实现文档.md)。
- **异步邮件**：验证码入队后由 user-service worker 异步发送，进度通过 SSE 推送给前端（`/api/v1/common/tasks/{task_id}/stream`）。
